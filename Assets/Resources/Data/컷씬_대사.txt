# NUMB 컷씬 대사 양식
#
# '#'으로 시작하는 줄은 설명이라 게임에 안 들어가요. 지우지 않아도 돼요.
#
# [적는 법]
#   이미지: 파일이름      → 이 줄 아래 대사들이 이 이미지 위에 나와요.
#                           파일 이름은 확장자(.png) 없이 적어 주세요.
#                           이미지 파일은 Assets/Resources/Cutscenes 폴더에 넣어 주세요.
#   이름: 대사            → 자막 한 줄 (클릭이나 스페이스바로 다음 줄)
#   내레이션: 대사        → 이름 없이 나오는 자막
#
#   - 한 이미지에 대사를 몇 줄이든 적을 수 있어요.
#   - 대사 한 줄 = 클릭 한 번이에요. 내레이션이 여러 개면 줄마다 "내레이션:"을 붙여 한 줄씩 적어 주세요.
#       내레이션: 기억 추출소의 아침은 늘 조용하다.
#       내레이션: 사람들은 이곳에서 기억을 팔아 빚을 갚는다.
#   - 한 자막 안에서 줄을 바꾸려면 그 자리에 / 를 넣어 주세요. (클릭 한 번에 두 줄로 나옴)
#       내레이션: 기억은 돈이 되고, / 돈은 빚이 된다.
#   - 다음 이미지로 바꾸려면 다시 "이미지: 파일이름"을 적으면 돼요.
#   - 쉼표, 따옴표, 말줄임표(…) 다 그냥 써도 돼요.
#   - 빈 줄은 무시되니 보기 편하게 띄워도 돼요.
#   - 쓰지 않는 컷씬은 대사 없이 비워 두면 그냥 건너뛰어요.
#
# 아래 예시 줄(예시라고 적힌 것)은 지우고 실제 대사로 바꿔 주세요.

[Tutorial.S1_T1.Start] 1일차 첫 서류: 시작
오틸리아: “베라 씨, 첫 업무입니다. 제가 순서대로 알려 드리죠.”
오틸리아: “거래가 도착하면 [서류 더미]를 클릭해 서류부터 펼치세요.”

[Tutorial.S1_T1.Open] 1일차 첫 서류: 서류를 펼침
오틸리아: “왼쪽이 신청서, 오른쪽이 계약서입니다.”
오틸리아: “{이름·기억 번호·기억 설명·서명}을 하나씩 비교하세요. {하나라도 다르면 승인해서는 안 됩니다.}”

[Tutorial.S1_T1.Stamp] 1일차 첫 서류: 도장 찍기 전
오틸리아: “문제가 없는 서류에는 [승인 도장]을 찍습니다.”
오틸리아: “도장은 {서류함에 넣기 전까지} 바꿔 찍을 수 있습니다.”

[Tutorial.S1_T1.File] 1일차 첫 서류: 서류함에 넣기 전
오틸리아: “{찍은 도장과 같은 서류함}에 넣으세요. {다른 서류함에 넣으면 수익은 없습니다.}”

[Tutorial.S1_T2.Start] 1일차 둘째 서류: 시작
오틸리아: “이번 서류에는 문제가 있습니다. 직접 찾아보세요.”

[Tutorial.S1_T2.Open] 1일차 둘째 서류: 서류를 펼침
오틸리아: “서로 다른 {두 항목을 모두 클릭}한 뒤 [기록]을 누르세요.”
오틸리아: “서명이 비어 있을 때는 {그 칸 하나만} 고르면 됩니다.”

[Tutorial.S1_T2.Stamp] 1일차 둘째 서류: 도장 찍기 전
오틸리아: “반려할 때는 {확실한 사유만} 고르세요. {틀린 사유가 하나라도 섞이면 수익은 없습니다.}”

[Tutorial.End.1] 1일차 튜토리얼 끝
오틸리아: “잘했습니다. 이제부터는 실제 거래입니다.”
오틸리아: “순서가 헷갈리면 책상 위의 [업무 지시문]을 다시 확인하세요.”

[Tutorial.S2_T1.Start] 2일차 서류: 시작
오틸리아: “오늘부터는 단말기로 기억 등록 기록까지 확인합니다.”
오틸리아: “먼저 [서류 더미]를 클릭해 기억 번호를 확인하세요.”

[Tutorial.S2_T1.Open] 2일차 서류: 서류를 펼침
오틸리아: “서류를 승인하기 전에 {기억 번호부터 확인}하세요. {번호가 다르면 전혀 다른 기억}을 조회하게 됩니다.”

[Tutorial.S2_T1.Record] 2일차 서류: 조회 기록이 나옴
오틸리아: “{번호만 같다고 바로 승인하면 안 됩니다.}”
오틸리아: “{기억 저장 시기와 서류의 내용이 일치하는지} 반드시 확인하세요.”

[Tutorial.S2_T1.Restore] 2일차 서류: 기억 복원 창
오틸리아: “섞인 기억을 {일어난 순서대로} 고르세요. {세 번 틀리면 그 거래의 수익은 없습니다.}”

[Tutorial.S2_T1.Restored] 2일차 서류: 복원을 마침
오틸리아: “{복원된 기억과 서류의 기억 설명}을 비교하세요. 다르면 반려해야 합니다.”

[Tutorial.End.2] 2일차 튜토리얼 끝

오틸리아: “{조회 기록의 번호가 서류와 같은지}, 도장을 찍기 전에 꼭 확인하세요.”
